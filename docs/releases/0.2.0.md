SSH Files 0.2 adds mouse navigation and selection to the two-pane SFTP browser.
Scroll the pane under the pointer, click a file, double-click a folder, or use
Ctrl-click, Shift-click and dragging to select a batch. Resize and listing changes
invalidate old mouse coordinates before they can act on another entry.

Hidden files are off by default. Press `.` with an empty filter to show or hide
them; the choice applies to both panes for this view. Hiding an entry removes it
from the marked batch. Recursive folder transfers still include their contents.

Windows ConPTY tests exercise the real input path; disposable OpenSSH tests cover
remote navigation, hidden files, actual transfers and cleanup. Hosted checks run
for Windows, Linux and macOS. macOS remains beta, and those checks do not replace
physical desktop qualification.

The compiled binaries need system OpenSSH and a working noninteractive SSH login.
They need no Python, Git or compiler. The release includes checksums and licenses.

Native OS file drag-in/out and transfer resume remain unfinished. F6 accepts
pasted local paths for reviewed upload; mouse range selection does not implement
dragging remote files into Explorer. The optional SSH Sessions Files chooser is
distributed by SSH Sessions, while `ssh-files --host ALIAS` opens an explicit route.
