# SSH Files 0.3.0

Select a whole filtered list with Ctrl+A, clear its marks with Ctrl+Shift+A,
and cycle name/size sorting with Ctrl+O. Folders stay first and the highlighted
entry keeps its identity when the order changes.

Insert opens a Create folder form for the selected pane. F9 confirms; Enter
leaves it open. Existing entries are preserved, and a cancelled operation with
an uncertain result retains its destination for inspection. Help now scrolls
at small terminal sizes.

The [feature inventory](https://github.com/brant92good/ssh-files/blob/v0.3.0/docs/file-manager.md)
lists implemented operations and the remaining gaps, including OS drag/drop,
existing-file maintenance and transfer resume.

This is a prerelease. The workflow publishes after all five native build and
package jobs pass, then tests the actual HTTPS installers. Check the
[release workflow](https://github.com/brant92good/ssh-files/actions/workflows/native.yml)
for final installer results. macOS desktop use remains **beta**.

Install a compiled binary using the commands in the
[README](https://github.com/brant92good/ssh-files/blob/v0.3.0/README.md#install).
Normal use needs system OpenSSH, without Python, Cargo or Git.
