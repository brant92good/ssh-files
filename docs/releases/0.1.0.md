SSH Files is a beta SFTP companion for existing OpenSSH routes: two file panes,
keyboard navigation and filtering, recursive transfer review, a serial queue,
progress and cancellation. F6 accepts local paths; F9 starts a reviewed transfer.

Use the alias directly, or pass an explicit hostname override while retaining
its SSH options. Existing final files are preserved. Interrupted finalization
is reported as unknown until the destination can be checked.

Assets contain the compiled UI only, with SHA-256 sidecars and license notices.
No Python, Cargo or Git runtime is required. System OpenSSH is required, along
with usable noninteractive credentials and verified host trust. Uploads require
the OpenSSH SFTP hardlink extension; local downloads require hardlink support.

This release does not provide native drag-out, resume, remote editing or delete.
macOS remains beta even when hosted build and terminal tests pass. Clipboard
copy uses the terminal's OSC52 policy. See the README for installation and the
verification record for tested platforms and remaining limits.
