# SSH Files 0.4.0-beta.1

This explicit beta adds Left/Right pane focus, marked-batch transfers by dragging
between panes, and all-or-nothing path paste. A plain drag starting on a marked
entry carries its whole marked batch, including movement within the source pane.
An unmarked or explicit range drag selects a range. A cross-pane drop starts the
frozen transfer plan; F6 retains the manual path editor and review flow.

The screen displays **BETA 0.4.0-beta.1**. Complete bracketed path paste can start
an upload after the whole input validates. Text delivered as separate Windows
key events opens a manual draft. Actual Explorer drag-in and drag-out remain
unqualified; this release does not incorporate the separate Windows reader or
output experiment. Existing collision, cancellation and uncertain-finalization
behavior is retained. macOS remains beta.

Use only the dedicated [beta installers](https://github.com/brant92good/ssh-files/blob/v0.4.0-beta.1/docs/beta-install.md), with an explicit
version and separate `ssh-files-beta` executable. The ordinary installer remains
pinned to 0.3.0; the existing Terminal Workspace bundle and its shortcuts are
unchanged. Installation does not open an SSH connection, launch the UI, write
PATH or register a Terminal profile.

The tag workflow requires five native target jobs before creating immutable
prerelease assets with `latest=false`. Each binary has a checksum sidecar, and
`release-record.json` binds the exact source, installer hashes, target gates and
all public payload hashes. LICENSE.txt and THIRD_PARTY_NOTICES.txt retain the
tagged source bytes. The record describes the pre-publication gate; subsequent
`released-install` jobs qualify actual HTTPS fresh/update installation on every
target, with both Windows PowerShell 5.1 and PowerShell 7 on Windows. Check the
tag workflow and its separate HTTPS receipts for final availability and results.
No published tag or asset is replaced after a failed gate.
